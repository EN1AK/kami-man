# Kami Man Bot 帮助

## 游戏王查卡

| 命令 | 说明 | 示例 |
|---|---|---|
| ck 卡名 | 查询单张卡片信息，包含卡图 | ck 青眼白龙 |
| 查卡 卡名 | ck 的中文别名 | 查卡 黑魔导 |
| 卡图 卡名 | 只查询卡图 | 卡图 灰流丽 |
| 卡价 卡名 | 文字模糊查价，默认日文；多张命中先回复编号选卡，再选罕贵，每步3分钟有效 | 卡价 原石 |
| 卡价 卡名 语种 罕贵 | 支持日文、简中、英文；价格按语种和卡包分别显示，人民币 | 卡价 原石之皇脉 简中 SR |
| pl 卡名 | 批量查卡，返回合并聊天记录 | pl 耀圣 |
| 批量查卡 卡名 | pl 的中文别名 | 批量查卡 白龙 |
| 裁定 卡名 | 查询卡片裁定，返回合并聊天记录 | 裁定 增殖的G |
| @神人 问题 | 群聊统一 Agent：聊天、游戏王/符文查卡、翻译与裁定，支持按群＋用户隔离的追问；私聊不触发 | @神人 有没有效果类似我身作盾的卡？ |
| @神人 翻译 文本 | 群聊 LLM 翻译，连接 ygo-rag agent；私聊不触发 | @神人 翻译 Once per turn: destroy it. |


普通用户每日可使用 Agent 30 次，按 QQ 号跨群共用，北京时间零点换日；管理员不限次数。翻译和符文规则／裁定别名共用额度，请求失败不扣次数。

`@神人 用量`：查看今日已用和剩余次数；`@神人 用量统计`：管理员查看今日用量统计。用量查询、空消息和清空对话不扣次数。

`@神人 清空对话`：清空你在当前群的对话上下文。引用机器人的回复也可以续聊。

## 符文战场

`@神人 查符文红色的6战力以上单位`：按卡库属性组合筛选。支持颜色、类型、能量、符文之力、战力、标签、英雄、地区、稀有度和系列；也可按效果描述找卡，例如“绿色中能保护其他单位的卡”。发送“下一页”或追加条件可以继续筛选。条件查询自动合并同卡版本，效果语义结果需结合卡文判断。

| 命令 | 说明 | 示例 |
|---|---|---|
| 符文卡价 卡名或编号 语种 | 集换社查价，默认简中；支持简中、繁中、英文、韩文 | 符文卡价 OGN-119 英文 |
| 符文卡价 完整卡名 语种 罕贵 | 副标题和异画分开查询；也可回复列表编号选择 | 符文卡价 阿狸 天真绮梦 简中 异画 |
| rb 卡名或编号 | 中英文、副标题和模糊查卡；同名卡返回候选 | rb 阿狸 |
| 符文查卡 卡名 | rb 的中文别名 | 符文查卡 沙丘亚龙 |
| rb 编号 | 查询指定普通、异画或超编版本 | rb OGN-066a |
| rbpl 卡名 | 批量查卡，合并转发，每次最多10种卡片 | rbpl 阿狸 |
| 符文批量 卡名 | rbpl 的中文别名 | 符文批量 阿狸 |
| 符文规则 问题 | 群聊规则问答 | 符文规则 什么是迅捷 |
| 符文裁定 问题 | 群聊裁定问答 | 符文裁定 沙丘亚龙的效果持续多久 |

## MyCard 录像与卡组归档

自动监听公开对局，官方竞技场名次前500的任一玩家参赛即可纳入采集。录像需要配置正常 MyCard 账号的观战凭据；不允许观战的房间会跳过。

| 命令 | 说明 | 权限 |
|---|---|---|
| MyCard采集状态 | 房间监听、账号配置、观战和归档状态 | 管理员 |
| 卡组查询 用户名 | 最新观测卡组、分享链接与 Side 说明；不填用户名时使用绑定账号 | 管理员 |
| MyCard卡组历史 用户名 | 连续历史卡组版本及最近归档ID | 管理员 |
| MyCard录像 用户名 | 最近10场收到录像的归档；不填用户名查看所有玩家 | 管理员 |
| MyCard文件 归档ID | 下载该场原始录像、每小局及汇总YDK、归档清单的ZIP | 管理员 |
| MyCard卡组文件 用户名 | 下载最新观测卡组YDK | 管理员 |
| 前排卡组信息 | 当前官方前100榜单及各玩家已归档卡组；采集范围仍是前500 | 全员 |

Side只记录实际观察到的换入卡，不代表完整备牌。卡组与录像文件仅保存在服务器，不提交到Git。


## MyCard 统计图表

统计图每天更新一次，收到查询命令才发送。卡片使用率取当前前500玩家各自最新观测卡组；对阵和影响度默认前100、近30天，可切换前500和1～90天。

| 命令 | 说明 | 示例 |
|---|---|---|
| 卡片使用率 [页码] | 主卡、观测Side投入率与去重总使用率；同名卡合并，显示1/2/3张投入占比 | 卡片使用率 2 |
| 额外卡组使用率 [页码] | 额外卡组单独统计使用率及投入张数分布 | 额外卡组使用率 |
| 卡组对阵胜率 [前100/前500] [天数] | 出场最多20个卡组大类的单页胜率热力图；默认前100、30天 | 卡组对阵胜率 |
| 卡组对阵胜率 前500 [天数] | 切换为采集时至少一方前500的对局样本 | 卡组对阵胜率 前500 7 |
| 卡片影响度 [前100/前500] [天数] | 同大类内携带/未携带胜率差；默认主卡、前100、30天，最多5张图合并为一条聊天记录 | 卡片影响度 |
| 卡片影响度 [前100/前500] [天数] 额外 | 查看额外卡组的携带胜率差，图片合并发送 | 卡片影响度 前500 额外 |
| 卡片影响度 [前100/前500] 天数 页码 | 指定页码时只发该页；组间按大类出场次数降序、组内按差值绝对值降序 | 卡片影响度 30 2 |

统计命令末尾加“文字”可看文字明细；例如“卡片影响度 前500 30 2 文字”“卡组对阵胜率 前100 30 2 文字”。对阵图只有一页，文字列表可翻页；卡片榜各最多100张，每页20张。

影响度只比较带/不带，不区分带1/2/3张的胜率；每个体系两组各至少20次对局、3位玩家。图中注明全部对照大类，多类结果为加权汇总；相关差异不是单卡的因果加成。Side不完整，不统计影响度。
